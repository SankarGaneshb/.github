# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest released versions of our projects on the default branch (`main` / `master`).

## Reporting a Vulnerability

If you discover a potential security vulnerability in any project under **SankarGaneshb**, please do NOT disclose it publicly via a GitHub Issue or Discussion.

Instead, please report the vulnerability responsibly:
1. Open a **Private Security Advisory** on the affected repository under the **Security** tab (`Security` -> `Advisories` -> `New draft security advisory`), OR
2. Contact the maintainer directly via GitHub profile: [@SankarGaneshb](https://github.com/SankarGaneshb).

Please include:
* Description of the vulnerability and potential impact.
* Steps or a proof-of-concept to reproduce the behavior.
* Recommended remediation or patch, if available.

We appreciate your effort in responsibly disclosing issues and will investigate and respond promptly.
